## Projects

I build these tools because I need them myself.

### Tools for AI coding agents

- **[seedr](https://github.com/danieldeusing/seedr)**: a CLI and web registry for coding agent content.
  One command installs skills, agents, hooks, plugins, MCP servers and settings for Claude Code, GitHub Copilot, Google Antigravity, Codex and OpenCode.
  Browse the registry at [seedr.danieldeusing.de](https://seedr.danieldeusing.de).
- **[Configr](https://github.com/danieldeusing/configr-releases)** (beta): a desktop app that shows what each coding agent really loads.
  You see skills, agents, commands, hooks, MCP servers and instruction files, where each one comes from, and whether it is in effect.
  Install on macOS with `brew install --cask danieldeusing/tap/configr`.
- **[Capi](https://github.com/danieldeusing/capi-cc-mod)**: a Claude Code mod that teaches a language above the prompt.
  Each card has one true fact and one expression, Brazilian Portuguese by default. I built it to learn Portuguese while Claude works ([the story](https://danieldeusing.de/articles/capi-claude-code-mod/)).
- **[digi-me](https://github.com/danieldeusing/digi-me)**: one personal "about me" for every coding agent and chat.
  Your facts stay in your own private repository and reach each device end-to-end encrypted. Each audience gets only the facts meant for it.

### Web and documents

- **[danieldeusing-design](https://github.com/danieldeusing/danieldeusing-design)**: the terminal design system (JetBrains Mono, four themes) for all my web pages and apps.
  One shared package stops copy-paste drift between them. Plain CSS and a vanilla-JS runtime, no build step needed.
- **[morning-briefs-daniel](https://github.com/danieldeusing/morning-briefs-daniel)**: a daily newsletter in 7 categories and 4 languages, live at [briefs.danieldeusing.de](https://briefs.danieldeusing.de).
  Claude Code agents research, write, translate and fact-check it. Each phase runs on the cheapest model that does its job well.
- **[cv-danieldeusing](https://github.com/danieldeusing/cv-danieldeusing)**: generates my CV as DOCX and PDF in four languages from one JSON file per language.
  The same data feeds the [CV page](https://danieldeusing.de/cv/) of my website.
- **[homebrew-tap](https://github.com/danieldeusing/homebrew-tap)**: the Homebrew tap for my macOS apps.
